# ТЗ: Веб-квест «Комната 1» (стиль Rusty Lake)

## 1. Общее описание

Point-and-click квест-игра для браузера. Один горизонтальный локейшн (комната) с
круговой навигацией по 4 стенам. Игрок кликает по объектам, собирает предметы в
инвентарь, решает головоломки, комбинирует предметы между собой.

- **Платформа:** веб (desktop + мобильный браузер, адаптивно)
- **Стек:** чистый HTML + CSS + JavaScript (без фреймворков и сборщиков)
- **Формат поставки:** один self-contained HTML-файл (или папка assets/ + index.html)
- **Стиль:** атмосферный, тёмный/уютный (как Rusty Lake), крупный план на
  интерактивных объектах, плавные переходы между видами

---

## 2. Архитектура

### 2.1 Стейт-машина сцены
Игра — это набор **экранов (views)**:
- 4 вида стен комнаты (круговая навигация ← →)
- Крупные планы (zoom-in) отдельных объектов: сапог, холодильник, фонограф,
  тумбочка, кровать/одеяло, зеркало, окно, горшок и т.д.
- Инвентарь — постоянная панель снизу/сверху

Каждый объект и каждая головоломка хранит свой **флаг состояния** (решено /
не решено / предмет забран), чтобы:
- при повторном заходе показывать актуальную картинку
- блокировать повторный сбор уже взятых предметов
- открывать зависимые события только после нужных условий

### 2.2 Инвентарь
- Горизонтальная панель с иконками предметов
- Клик по предмету → «взять в руку» (курсор меняется на иконку предмета)
- Клик предметом по объекту сцены → попытка применить
- Комбинирование предметов: клик предмет A → клик предмет B в инвентаре →
  либо крафт нового предмета, либо сообщение «ничего не получится»

### 2.3 Переходы
- Fade/cross-fade между видами стен и крупными планами (200–400 мс)
- Спрайт-анимации «одноразовых событий» (рост цветка, трещины на зеркале,
  разрезание игрушки) — либо покадровая анимация (sequence of PNG), либо
  CSS/SVG анимация

## 3. Список механик (по сценарию)

| № | Механика | Тип |
|---|----------|-----|
| 1 | Навигация по 4 стенам, круговая (Prev/Next) | Навигация |
| 2 | Скрытая подсказка в декоративной рамке картины (азбука Морзе точки/тире) | Поиск подсказки |
| 3 | Ввод последовательности: клик по двум банкам (жёлтая=точка, коричневая=тире) в сапог в нужном порядке | Секвенция/ввод кода |
| 4 | Проверка последовательности → успех/сброс при ошибке | Валидация |
| 5 | Простой сбор предмета (стакан из холодильника) | Pick-up |
| 6 | Применение предмета на объект (нож → мясо) → получение нового предмета | Инструмент-действие |
| 7 | Вставка предмета в объект (валик → фонограф) → анимация → открытие отсека | Триггер-событие |
| 8 | Посадка предмета (луковица → горшок) | Pick&place |
| 9 | Наблюдение/запоминание (птицы на окнах — паттерн) | Мемори-паттерн |
| 10 | Крупный план одеяла — грид ячеек с бусинами, клик в нужном порядке по координатам, повторяющим паттерн птиц | Grid-паттерн по мемори |
| 11 | Открытие тайника под одеялом → предмет | Reveal |
| 12 | Применение ножа на предмет в инвентаре → замена предмета (игрушка → сердце) | Инвентарный крафт |
| 13 | Мульти-крафт: 3 предмета применяются по очереди на стакан → готовая смесь | Крафт-цепочка |
| 14 | Вылить смесь в горшок → анимация мгновенного роста растения | Триггер-анимация |
| 15 | Применить нож на цветок (крупный план) → надрез | Инструмент-действие на сцене |
| 16 | Клик рукой (без предмета) по объекту → отламывание части + спрайт сока | Прямое взаимодействие |
| 17 | Применить стакан на капающий спрайт → сбор жидкости | Pick-up через предмет |
| 18 | Найти мелкий предмет на общем плане (салфетка за ножкой кровати) | Скрытый pick-up |
| 19 | Комбинирование 2 предметов в инвентаре (салфетка + сок) → новый предмет | Инвентарный крафт |
| 20 | Скрытая подсказка на изголовье кровати (порядок очистки пятен) | Поиск подсказки |
| 21 | Крупный план тумбочки — клик по пятнам в заданном порядке мокрой салфеткой, сброс при ошибке | Секвенция по подсказке |
| 22 | Финал: зеркало + портрет-подсказка → клик предметом за «ухо» персонажа | Финальное действие |
| 23 | Каскад: трещины → осколок падает → ниша с секретным предметом | Cutscene + reveal |

**Итого типов игровых паттернов, которые нужно реализовать программно (переиспользуемые модули):**
1. `SequenceInput` — ввод последовательности кликов с проверкой порядка (используется в п.3 и п.21)
2. `MemoryPattern` — где игрок должен запомнить расположение и повторить его на другом объекте (п.9→10)
3. `CraftChain` — применение нескольких предметов на один объект-контейнер по очереди (п.13, 19)
4. `HotspotReveal` — клик по объекту открывает новый объект/предмет (пики, ниши, отсеки)
5. `ZoomView` — переход с общего плана на крупный план конкретного объекта и обратно
6. `OneShotAnimation` — необратимая анимация события (рост цветка, трещины, разрезание)

## 4. UI/UX требования

- Курсор меняет вид при наведении на интерактивный объект (лёгкое свечение/подсветка hotspot при hover — по вкусу, можно и без, в духе Rusty Lake обычно без явных подсветок)
- Инвентарь: иконки 48–64px, подсветка выбранного предмета
- Крупные планы открываются по клику и закрываются по кнопке «назад» / клику вне объекта
- Индикация ошибки в секвенциях — короткая визуальная реакция (тряска/вспышка), затем сброс
- Звук: клики, успех головоломки, фоновая эмбиент-музыка (опционально, если есть ассеты)
- Адаптив: на мобильном — те же сцены, увеличенные хитбоксы под тач

## 6. Этапы разработки

1. Вёрстка базового каркаса: навигация по 4 стенам + система состояний
2. Инвентарь + логика pick-up / apply / combine
3. Реализация переиспользуемых модулей (`SequenceInput`, `MemoryPattern`, `CraftChain`, `ZoomView`)
4. Наполнение сцены конкретными объектами и хардкод-логикой головоломок по сценарию
5. Анимации и переходы
6. Звук (если есть ассеты)
7. Полное прохождение и баг-фикс
8. Адаптация под мобильный экран
