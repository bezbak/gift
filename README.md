# Комната 1 — веб-квест (прототип)

Реализация по `tz_2.md` (сценарий v2, 34 шага) и `TZ_komnata_1.md` (тех. ТЗ).
Старый сценарий на 28 шагов — `tz_1.md` (устарел).
Стек: чистый HTML + CSS + JS, без сборки.

## Запуск

Открыть `index.html` в браузере (Chrome/Edge/Firefox). Локальный сервер не нужен —
скрипты подключены обычными `<script src>` (не ES-модули), пути относительные.

## Структура файлов

```
index.html          — разметка + подключение css/js
css/styles.css      — все стили (сцена 4:3, инвентарь под сценой, анимации)
js/models.js        — МОДЕЛИ: данные и состояние (ITEMS, MORSE, FRIDGE_CODE, WINDOW_PATTERN,
                      STAIN_ORDER, TABLE_*, MAP_*, S — стейт с флагами). Грузится первым.
js/functions.js     — ФУНКЦИИ: движок и логика — Audio2, hotspot/makeDrag, действия по шагам
                      сценария (morseTap, fridgeTurn, quiltChanged, mixerUse, potUse, stainTap,
                      flowerOnEar, openDoor, tableMove, paintingUse, mapUse, finale…),
                      tryCombine, рендер, навигация, подсказки.
js/art.js           — ГРАФИКА-ПЛЕЙСХОЛДЕРЫ: SVG-рисунки и геометрия (Frame, cropBox, spriteDiv)
js/scenes.js        — ВИДЫ: buildScene() — описания 4 стен и всех крупных планов + cineHTML()
js/selftest.js      — АВТОТЕСТ: полное прохождение всех шагов (?selftest)
js/main.js          — ЗАПУСК: обработчики кнопок/клавиш, прелоад, dev-хуки URL
assets/images/      — графика
```

Порядок загрузки: `models → functions → art → scenes → selftest → main` (общая глобальная область).

### Как расширять

- **новый предмет** — запись в `ITEMS` (`js/models.js`)
- **новый флаг прогресса** — поле в `S.f` (`js/models.js`)
- **новый объект / крупный план** — новый `case` в `buildScene()` (`js/scenes.js`), переход — `go("<id>")`
- **заменить плейсхолдер настоящим артом** — в нужном `case` убрать `Frame(...).svg(art…)` и положить
  `layerImg("файл.png")`, хитбоксы подправить в %; стыковка по координатам — через `Frame.r()/pt()`
- **новый рецепт в инвентаре** — строка в таблице `R` внутри `tryCombine()`

## Управление

- Стрелки по краям или `←`/`→` — круговая навигация по 4 стенам; `Esc` / «← назад» — выйти из крупного плана.
- Клик по объекту — осмотр / крупный план / действие рукой.
- Клик по предмету в инвентаре — взять «в руку», повторный клик — положить; фото раскрывается кликом.
- Предмет «в руке» + клик по объекту — применить; «в руке» + клик по другому предмету в инвентаре — совместить.
- Бусины и фишки на столе — перетаскиваются (мышь и тач).
- `?` — подсказка по текущему шагу, `D` — показать хитбоксы.

## Раскладка стен

| Стена | Что на ней |
|---|---|
| 0 (новый арт) | кровать (одеяло, изголовье), сапог, тумбочка (ящик, крышка с пятнами), полка (валик, горшок), плакат с Морзе (правая рама), жёлтая картина (булавка), салфетка на полу |
| 1 | два окна с птицами/яйцами, фонограф, мини-холодильник с кодовым замком, смеситель (на холодильнике) |
| 2 | зеркало Вари → дверь, портрет-подсказка, пустая рама для карты, выключатель |
| 3 | стол с таблицей и листком, прожектор |

## Решения головоломок (для теста)

- **Морзе (плакат → сапог):** `— · · — · —` → коричневая, жёлтая, жёлтая, коричневая, жёлтая, коричневая.
  Правые квадранты плаката нарисованы зеркально (`— · — · · —`) — этот порядок тоже принимается.
  Ошибка → жижа сама стекает. Банки и сапог — на крупном плане сапога.
- **Холодильник:** код `ДИТЯ` (нацарапан на открытом нижнем ящике тумбочки), 4 барабана с буквами ▲▼.
- **Память (окна → одеяло):** сетка 4×2 (слева-направо, сверху-вниз). Птицы (большие бусины) — ячейки `1, 4, 6`,
  яйца (маленькие) — `3, 7`. Остальные ячейки пусты.
- **Смеситель:** стакан → сердце, анилин, чай (в любом порядке); лишние предметы возвращаются.
- **Пятна (изголовье → крышка тумбочки):** порядок цветов человечков слева направо: красный, синий, зелёный,
  бирюзовый, жёлтый. Ошибка → все пятна восстанавливаются.
- **Зеркало:** надломленный цветок — за **правое** ухо (как на портрете); осколок падает → ниша с пазлом;
  выйти из зума → дверь → открыть → тень, затемнение → зеркало с синяком → лёд → дыра → карта.
- **Стол:** кот 2, олень 2, цветок 4, глаз 3 (клик по клетке строки или перетаскивание фишки).
- **Прожектор/выключатель:** провод → прожектор → люк → клавиша → выключатель → выключить свет → нож по картине
  (до починки выключателя и при включённом свете — запрещено). После булавки свет включается сам.
- **Финал:** на фото человек между маяком и мельницей → булавка в середину между ними на карте.

## Ассеты

**Настоящая графика (`assets/images/`):** `wall_bed` (стена 0), `poster_zoom`, `boot_empty/yellow/brown`,
`bed_zoom(_open)` (изголовье/одеяло/матрас — три панели в одном файле, режутся кодом), `nightstand_zoom(_open)`,
`stain_*` (5 цветов), `handkerchief`, `room_bg` (пустая стена), `bed`/`nightstand`/`painting` (спрайты — используются
в финальном полёте).

**Плейсхолдеры (SVG в `js/art.js`):** окна и пуговицы-птицы, фонограф, холодильник и замок, смеситель, зеркало и
Варя, портрет, дверь с тенью, рама и карта мира, стол, прожектор, выключатель, горшок/цветок/сок, зайчик, нож,
предметы-иконки (emoji), фото, рука и Варя в финале.

**Не используются:** `screwdriver.png`, `button.png` (были в сценарии v1), а также `ChatGPT Image *` и
`Снимок экрана *` — не относятся к игре.

## Допущения (проверить с Полиной)

- Правая красно-коричневая рама на стене 0 = плакат с Морзе (на крупном плане та же рама). «Пустая рама» для
  карты — отдельный плейсхолдер на стене 2.
- Окна: 2 окна × 4 стекла = 8 ячеек, как на одеяле; расположение птиц/яиц выбрано мной (см. `WINDOW_PATTERN`).
- Порядок очистки пятен = цвета человечков слева направо (раньше стоял выдуманный порядок).
- Фото и карта — плейсхолдеры (маяк/мельница); достаточно заменить `photoSVG()`/`artMap()` и `MAP_TARGET`.
- Кусочки цветка-пазла (шаг 29) пока нигде не используются — задел под комнату 2.

## Dev-хуки (query-параметры)

- `?selftest` — автопрохождение всех шагов с отчётом PASS/FAIL (`document.title`).
- `?start` — пропустить титульный экран; `?debug` — показать хитбоксы.
- `?view=<id>` — стены `wall0..wall3` и крупные планы: `poster`, `boot`, `nightstand`, `stains`, `headboard`,
  `quilt`, `pot`, `fridge`, `phono`, `mixer`, `mirror`, `portrait`, `table`, `projector`, `switch`, `map`.
- `?give=knife,glass_empty` — выдать предметы; `?set=morse,mirrorStage=2` — выставить флаги `S.f`;
  `?state={"bootFill":"yellow"}` — слить JSON в `S`; `?cine=p2,p3` — показать фазы финальной сцены.
