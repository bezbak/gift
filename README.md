# Комната 1 — веб-квест (прототип)

Реализация по `TZ_komnata_1.md` (тех. ТЗ) и `tz_1.md` (сценарий, 28 шагов).
Стек: чистый HTML + CSS + JS, без сборки.

## Запуск

Открыть `index.html` в браузере (Chrome/Edge/Firefox). Локальный сервер не нужен —
скрипты подключены обычными `<script src>` (не ES-модули), пути относительные.

## Структура файлов

```
index.html          — разметка + подключение css/js
css/styles.css      — все стили
js/models.js        — МОДЕЛИ: данные и состояние (ITEMS, MORSE, BIRD_CELLS,
                      STAIN_ORDER, S — стейт с флагами). Загружается первым.
js/functions.js     — ФУНКЦИИ: движок и логика — Audio2, buildScene() (описания
                      всех видов), головоломки (morseTap/quiltTap/stainTap/
                      tryCombine), рендер, навигация, подсказки, selfTest().
js/main.js          — ЗАПУСК: обработчики кнопок/клавиш, прелоад, первый
                      refresh(), разбор dev-параметров URL. Только связывание.
assets/images/      — графика
```

Порядок загрузки: `models.js` → `functions.js` → `main.js` (все три делят общую
глобальную область; классические скрипты видят объявления предыдущих).

### Как расширять

- **новый предмет** — запись в `ITEMS` (`js/models.js`)
- **новый флаг прогресса** — поле в `S.f` со значением `false` (`js/models.js`)
- **новый объект / крупный план / комната** — новый `case` в `switch` внутри
  `buildScene()` (`js/functions.js`); переход — `go("<id>")`
- **новый рецепт комбинирования** — строка в таблице `R` внутри `tryCombine()`
- **новая головоломка-константа** — в `js/models.js` по образцу `MORSE`/`STAIN_ORDER`

## Управление

- Стрелки-стены слева/справа или `←`/`→` — круговая навигация по 4 стенам.
- Клик по объекту — осмотр / крупный план.
- Клик по предмету в инвентаре — взять «в руку», повторный клик — положить.
- Предмет «в руке» + клик по объекту сцены — применить.
- Предмет «в руке» + клик по другому предмету в инвентаре — комбинировать.
- `←ㅤназад` / `Esc` — выйти из крупного плана.
- Кнопка `?` — контекстная подсказка по текущему шагу.
- `D` — показать хитбоксы (отладка).

## Раскладка стен

| Стена | Что на ней |
|---|---|
| 0 | Кровать (одеяло-грид, изголовье), тумбочка (ящик, крышка с пятнами), салфетка на полу |
| 1 | Окна с птицами, горшок на подоконнике, полка с валиком, фонограф, мини-холодильник |
| 2 | Картина с рамкой-Морзе, портрет-подсказка, зеркало Вари |
| 3 | Чугунный сапог, 2 банки (жёлтая / коричневая) |

## Решения головоломок (для теста)

- **Морзе (картина → сапог):** `· · — ·` → жёлтая, жёлтая, коричневая, жёлтая.
  Жёлтая жижа = точка, коричневая = тире. Ошибка → сброс.
- **Память (окна → одеяло):** птицы сидят в ячейках `1, 3, 4, 6` (сетка 4×2, слева-направо,
  сверху-вниз, с 0). Нажимать по возрастанию. Ошибка → сброс.
- **Пятна (изголовье → крышка тумбочки):** порядок `жёлтое, голубое, красное, зелёное, синее`.
  Тереть мокрой салфеткой. Ошибка → все пятна возвращаются.
- **Крафт-цепочка:** пустой стакан + сердце + анилин + чай → питательная смесь.
- **Комбо в инвентаре:** нож + игрушка → сердце; сухая салфетка + стакан с соком → мокрая салфетка.
- **Финал:** надломленный цветок Варе за ухо → зеркало трескается → отвёрткой подцепить
  осколок → в нише **пуговица** (крючок-переход в комнату 2).

## Ассеты

**Настоящая графика (`assets/images/`):** `room_bg`, `bed`, `nightstand`, `bed_zoom(_open)`,
`nightstand_zoom(_open)`, `painting`, `handkerchief`, `screwdriver`, `button`, `stain_*` (5 цветов).

**Плейсхолдеры (CSS/SVG в коде):** сапог, банки, холодильник, фонограф, валик, окна с птицами,
горшок/цветок, зеркало, портрет, нож, стакан, анилин, чай, луковица, игрушка, сердце.
Заменяются подстановкой файла и правкой соответствующего блока в `buildScene()`.

Файлы `ChatGPT Image *`, `Изображение Codex *`, `Паркинг`, `Дизайн без названия`,
`Снимок экрана *` — не относятся к игре (архитектурные рендеры / планировки), не используются.

## Ключевые сущности кода

- `S` (`models.js`) — единый стейт: `view`, `wallIndex`, `inv[]`, `selected`, `S.f{}` — флаги всех головоломок/предметов.
- `ITEMS` (`models.js`) — реестр предметов (имя + опц. картинка иконки).
- `buildScene()` (`functions.js`) — по `S.view` возвращает `{layers, nodes, hs}`; вызывается из `refresh()`.
- `hotspot({r:[l,t,w,h]%, title, zoom, click, use(item)})` — зоны клика в процентах, адаптив.
- Переиспользуемые механики: `morseTap` (SequenceInput), `quiltTap` (MemoryPattern),
  `stainTap` (SequenceInput по подсказке), `tryCombine`/`craftMix` (CraftChain), `go()` (ZoomView + fade).
- Звук — мини-синтез на WebAudio (`Audio2`), без файлов.

## Dev-хуки (query-параметры)

- `?selftest` — автопрохождение всех 28 шагов с отчётом PASS/FAIL.
- `?start` — пропустить титульный экран.
- `?view=wall1` (или `quilt`, `stains`, `painting`, `boot`, `fridge`, `phono`, `nightstand`, `pot`, `mirror`, `headboard`).
- `?give=knife,glass_empty` — выдать предметы.
